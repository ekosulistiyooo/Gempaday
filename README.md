# Gempaday

A simple React app to display recent earthquake data from the BMKG API.

## Features
- Fetch earthquake data from BMKG
- Display the latest earthquake information
- Show earthquake magnitude, depth, and location
- Responsive UI for desktop and mobile

## Requirements
- Node.js 18 or newer
- npm

## How to run
1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the app in your browser:
   ```bash
   http://localhost:3000
   ```

## Build for production
```bash
npm run build
```

## Preview production build
```bash
npm run preview
```
